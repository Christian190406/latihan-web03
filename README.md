## 📌 About the Project

Latihan Web03 adalah proyek latihan pembuatan website
satu halaman (*one-page website*) menggunakan HTML dan CSS.

Proyek ini menggunakan elemen `div` untuk menyusun layout
tanpa menggunakan tabel HTML. CSS ditulis dalam file
terpisah agar struktur dan tampilan mudah dikelola.

## ✨ Features

- 🏠 **Home** — navigasi dan hero section.
- 🧩 **Services** — tiga kolom informasi layanan.
- 👋 **About** — deskripsi dan ilustrasi Performance.
- ✉️ **Contact** — formulir nama, email, dan pesan.
- 📱 **Responsive Design** — menyesuaikan ukuran layar.
- 🎨 **Pastel Color Palette** — warna lembut untuk setiap section.
- 🔗 **Anchor Navigation** — menu menuju section terkait.

## 🛠️ Built With

- Flexbox
- SVG

## 🚀 How to Run

1. Clone atau download repository ini.
2. Buka folder proyek di Visual Studio Code.
3. Buka file `index.html` di browser.
4. Kamu juga bisa menggunakan ekstensi Live Server.

## 🌍 Deploy with GitHub Pages

1. Upload semua file ke repository GitHub.
2. Buka **Settings → Pages**.
3. Pilih **Deploy from a branch**.
4. Pilih branch `main` dan folder `/ (root)`.
5. Klik **Save** dan tunggu proses deployment selesai.

## 📝 Notes

- Layout dibuat menggunakan `div`, tanpa tabel.
- File HTML dan CSS dipisahkan.
- Formulir kontak hanya untuk tampilan dan belum
  terhubung ke backend untuk mengirim pesan.
